# Public-Job-Collector
An n8n automation project that collects public job listings from multiple sources, classifies them, and stores them in PostgreSQL.


Tech Stack
n8n — Workflow automation
PostgreSQL 16 — Job database
Docker Desktop — Local containers
Adminer — Browser-based database management
